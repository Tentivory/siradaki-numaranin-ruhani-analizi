# Sıradaki Numaranın Ruhani Analizi

Bu proje, bir bekleme salonunda elinizde tuttuğunuz kâğıt parçasının aslında bir kehanet belgesi olduğunu bilimsel olarak (yani hiç bilimsel olmadan) ispatlar.

Eczane sırası, vergi dairesi, muayenehane, kargo şubesi veya "numara alınız" yazan her yer için geçerlidir. Yazılım numaranızı okur, kaderinizi yazar, sonra da sizi biraz azarlar.

## Neden var?

Çünkü sırada dururken telefonu kaydırmak yetmiyordu. Bir de kader analizi lazımdı.

## Kuruluş

```bash
python3 analiz.py 47
```

Numara vermezseniz program size numara verir. Vermek istemezseniz de verir. Özgür irade burada dekoratiftir.

## Örnek çıktı

Program çalıştığında aşağıdakine benzer bir rapor basar:

- ruh hali
- beklenen süre (uydurma)
- yanlış kata basma ihtimali
- çay içilip içilmeyeceği
- varoluşsal dipnot
